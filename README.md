# 🤖 نقلی‌استودیو — ربات خودکار تولید و انتشار ویدئوی کودک در تیک‌تاک

پنل فرماندهی تمام‌خودکار برای ساخت ویدئوهای کودکانه: ایده، انیمیشن، صداگذاری، رندر، زمان‌بندی و آپلود در تیک‌تاک — همراه با ربات تلگرام برای مدیریت از راه دور.

> ⚡ همه‌چیز خودکار است: موتور پایپ‌لاین هر چند ثانیه تولید را جلو می‌برد، در بهترین ساعت زمان‌بندی می‌کند، منتشر می‌کند و آمار را به‌روز می‌کند.

# 🚀 راه‌اندازی سریع (۵ دقیقه)

## پیش‌نیازها

- سرور مجازی (VPS) با **Ubuntu 22.04** یا **Debian 12** — حداقل ۲ گیگ رم
- یک **دامنه** که رکورد A آن به آی‌پی سرور وصل باشد (برای وب‌هوک تلگرام و SSL)
- دسترسی روت با SSH

## ۱) انتقال پروژه به سرور

```bash
# روی کامپیوتر خودتان
scp -r naqoli-studio/ root@YOUR_SERVER_IP:/root/naqoli-studio

# یا اگر روی گیت‌هاب کلون شده:
git clone <آدرس مخزن> /root/naqoli-studio
```

## ۲) اجرای اسکریپت راه‌انداز

اسکریپت `setup.sh` همه‌چیز را خودکار نصب می‌کند:

```bash
cd /root/naqoli-studio
sudo bash setup.sh --domain yourdomain.com
```

کارهایی که اسکریپت انجام می‌دهد:

- ✅ نصب Node.js 22 و PostgreSQL
- ✅ ساخت دیتابیس با رمز امن تصادفی + فایل `.env`
- ✅ نصب وابستگی‌ها، اعمال اسکیما (`drizzle-kit push`) و درج داده‌های نمونه
- ✅ بیلد پروداکشن و سرویس `systemd` که بعد از ری‌استارت سرور خودکار بالا می‌آید
- ✅ نصب Caddy و صدور **گواهی SSL رایگان** برای دامنه شما

### فلگ‌های اختیاری

| فلگ | کاربرد |
| --- | --- |
| `--domain example.com` | دامنه شما + نصب خودکار Caddy و SSL |
| `--port 8080` | پورت دلخواه (پیش‌فرض: ۳۰۰۰) |
| `--app-dir /opt/app` | محل نصب دلخواه |
| `--db-pass mypass` | رمز دیتابیس دلخواه |
| `--update` | به‌روزرسانی کد، بیلد مجدد و ری‌استارت |
| `--status` | گزارش سریع سلامت سرویس |

## ۳) بررسی اجرا

```bash
sudo systemctl status naqoli     # باید «active (running)» ببینید
journalctl -fu naqoli            # لاگ زنده
```

پنل را باز کنید: `https://yourdomain.com` یا بدون دامنه `http://IP:3000` 🎉

# 📱 اتصال واقعی ربات تلگرام

1. در تلگرام به **@BotFather** بروید و با `/newbot` یک ربات بسازید؛ توکن دریافت می‌کنید.
2. در پنل، بخش **«ربات تلگرام ← پیکربندی اتصال ربات»** توکن و شناسه چت خود را ذخیره کنید.
3. وب‌هوک را ثبت کنید تا پیام‌ها به سرور شما برسند:

```bash
curl -F "url=https://yourdomain.com/api/webhook" \
     "https://api.telegram.org/bot<TOKEN>/setWebhook"
```

4. بررسی:

```bash
curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
```

تمام! حالا ربات پیام‌های واقعی را پردازش می‌کند و دستورهای `/video`، `/stats`، `/pause` و… واقعاً اجرا می‌شوند.

# 🎵 اتصال انتشار تیک‌تاک

برای آپلود واقعی ویدئوها به مجوز رسمی **TikTok for Developers** نیاز دارید:

1. در `developers.tiktok.com` اپلیکیشنی با دسترسی **Content Posting API** ثبت کنید.
2. بعد از تأیید، توکن‌ها را در `/var/www/naqoli-studio/.env` قرار دهید:

```env
TIKTOK_CLIENT_KEY=xxxx
TIKTOK_CLIENT_SECRET=xxxx
TIKTOK_ACCESS_TOKEN=xxxx
```

3. ری‌استارت کنید: `sudo systemctl restart naqoli`

> تا قبل از دریافت توکن، پنل در حالت شبیه‌سازی انتشار کار می‌کند تا کل جریان کاری را زنده ببینید.

# 🔧 دستورات مدیریت روزمره

```bash
sudo systemctl status naqoli       # وضعیت سرویس
sudo systemctl restart naqoli      # ری‌استارت
journalctl -fu naqoli              # لاگ زنده
sudo bash setup.sh --update        # به‌روزرسانی کد + بیلد
sudo bash setup.sh --status        # گزارش سلامت
```

# 💾 پشتیبان‌گیری

```bash
# بکاپ دستی (رمز دیتابیس در .env ذخیره شده)
PGPASSWORD="رمز" pg_dump -h 127.0.0.1 -U postgres app_db > backup.sql

# بکاپ خودکار روزانه ساعت ۳ بامداد
echo '0 3 * * * PGPASSWORD="رمز" pg_dump -h 127.0.0.1 -U postgres app_db > /root/backups/db-$(date +\%F).sql' | crontab -
```

# 🩺 عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| خطای پورت | `sudo bash setup.sh --port 8080 --domain …` |
| خطای اتصال دیتابیس | `sudo systemctl status postgresql` و بررسی `DATABASE_URL` در `.env` |
| شکست بیلد با کمبود رم | ساخت سواپ ۲ گیگی: `sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile` |
| خطای ۵۰۲ روی دامنه | بررسی رکورد A + `sudo systemctl restart caddy` |
| ربات پاسخ نمی‌دهد | خروجی `getWebhookInfo` را ببینید؛ توکن باید در پنل ذخیره شده باشد |
